# Event-Study Methods（方法口径）

本 skill 实现的是教科书式、可审计的**市场调整 / 均值调整**事件研究，优先透明而非复杂因子模型。

## 异常收益（AR）

### Market-adjusted（默认）

\[
AR_{i,t} = R_{i,t} - R_{m,t}
\]

- \(R_{i,t}\)：个股日收益  
- \(R_{m,t}\)：市场日收益（用户 CSV，或**当日收益面板截面等权均值**）

优点：无估计参数、无前视；缺点：未剥离 beta / 行业暴露。

### Mean-adjusted

\[
AR_{i,t} = R_{i,t} - \hat\mu_i,\quad
\hat\mu_i = \overline{R_{i,\tau}},\ \tau\in[T_0,T_1]
\]

默认估计窗 **[−120, −21]**（相对事件交易日），**严格止于事件前**，不得包含 τ=0。

估计样本过稀（有效天数不足）的事件剔除。

## 累计异常收益（CAR）

对事件 \(i\)、窗口 \([L,R]\)：

\[
CAR_i[L,R] = \sum_{\tau=L}^{R} AR_{i,\tau}
\]

默认报告窗口：`[-1,1]`（主）、`[-1,0]`、`[0,1]`、`[-5,5]`、`[-10,10]`（裁剪到 `--pre/--post`）。

恒等式：`CAR[-1,1] = AR(-1)+AR(0)+AR(1)`（缺失日会导致该事件 CAR 为 NaN 并在截面中剔除）。

## 截面检验

对每个窗口，取 \(\{CAR_i\}\)：

1. **单样本 t 检验** \(H_0: E[CAR]=0\) — Student-t 双侧 p（非正态近似）  
2. **符号检验** \(H_0: P(CAR>0)=0.5\) — 二项精确双侧 p  
3. 报告：N、mean、median、std、t、p、胜率、是否 p<0.05

## 日历对齐

- 交易日日历 = 收益与市场日期并集（排序）  
- 事件日：优先精确匹配；否则取 **on-or-after** 下一交易日（停牌/非交易日）  
- 事件窗 `[−pre,+post]` 越界 → 剔除  

## 缺失与样本量护栏

| 规则 | 行为 |
|------|------|
| 事件窗内 AR 缺失比例 > 30% | 剔除事件，`n_dropped_missing++` |
| 可用事件 N < 20 | **拒绝**出报告 |
| 20 ≤ N < 50 | 出报告但 **low_sample_warning** |
| 重叠事件 | 不自动聚类；在 caveats 中提示截面非独立 |

## 与经典文献的关系

- Brown & Warner (1980/1985)、MacKinlay (1997) 框架下的简化实现  
- **未实现**：市场模型 OLS beta、Fama-French、Boehmer 等异方差稳健、日历时间组合  
- 若用户需要 beta 调整或行业中性，应换用扩展模型并在报告中改写口径，而不是 silently 假装已调整

## 解读建议

- 先看 **N_used / N_dropped**，再看主窗口  
- 多窗口同号且显著 → 稳健性更好；仅单窗口显著 → 标注脆弱  
- 胜率与 mean CAR 分歧时，检查极端值 / 偏态  
- 永远区分：**统计显著 ≠ 可交易 α**（成本、可撮合、重叠、选样偏差）
